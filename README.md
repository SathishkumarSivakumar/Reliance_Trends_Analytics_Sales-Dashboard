# Excel Sales Dashboard

## Project Overview

This project is an interactive Sales Dashboard developed using Microsoft Excel.

The dashboard helps analyze sales performance, products, customers, stores,
profit and other business metrics using interactive Excel features.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Form Controls
- Excel Formulas
- Conditional Formatting
- Data Analysis

## Key Features

- Sales KPI
- Profit KPI
- Total Orders
- Sales Performance Analysis
- Product Analysis
- Customer Analysis
- Store Performance
- Interactive Slicers
- Form Control-based filtering
- Dynamic Dashboard

## Excel Functions Used

- SUM
- SUMIF
- SUMIFS
- COUNT
- COUNTIF
- COUNTIFS
- AVERAGE
- MAX
- MIN
- IF
- IFERROR
- VLOOKUP
- XLOOKUP
- TODAY
- NOW
